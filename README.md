# Анализ жанров Metroidvania и Horror на данных Steam

Сравнительный анализ двух популярных у инди-разработчиков категорий на платформе Steam для принятия решения о разработке инди-игры.

## О проекте

**Бизнес-вопрос:** какой жанр — Metroidvania или Horror — более перспективен для инди-разработки?

**Цель:** провести сравнительный анализ двух категорий по ключевым метрикам (рейтинг, цена, конкуренция) и сформулировать рекомендацию для разработчика.

## Данные

- **Источник:** [Steam Games Dataset (March 2026)](https://www.kaggle.com/datasets/ebrucakar/steam-games-dataset-march-2026) на Kaggle
- **Объём:** 115 289 игр, 40 колонок
- **Ключевые поля:** Name, Genres, Tags, Price, Positive, Negative, Release date

## Инструменты

- **Python:** pandas, NumPy, Matplotlib, Seaborn, SciPy
- **ML:** scikit-learn, LightGBM
- **BI:** Yandex DataLens
- **Среда:** Jupyter Notebook

## Что сделано

### 1. Очистка данных
- Удалены колонки с высоким процентом пропусков (>50%)
- Заполнены пропуски в текстовых колонках
- Созданы производные признаки: `rating` (процент положительных отзывов), `year`
- Проведён контроль качества через `assert`

### 2. Разведочный анализ (EDA)
- Топ-10 жанров по количеству игр
- Сравнение Metroidvania и Horror по цене и рейтингу
- Динамика релизов по годам

### 3. Статистический анализ
- **Тест Шапиро-Уилка** — проверка нормальности распределения
- **Тест Манна-Уитни** — сравнение двух взаимоисключающих групп
- **Размер эффекта (rank-biserial)** — оценка практической значимости

### 4. Дополнительный анализ
- **Анализ выбросов (метод IQR)**
- **ABC-анализ** игр по количеству отзывов

### 5. Машинное обучение
- Задача: бинарная классификация — предсказать "успешность" игры (рейтинг ≥ 80%)
- Модели: Logistic Regression, Random Forest, LightGBM
- Лучший результат: LightGBM (Accuracy 0.6169)

## Ключевые результаты

| Показатель | Metroidvania | Horror |
|------------|--------------|--------|
| Количество игр | 1 321 | 9 586 |
| Средний рейтинг | **80.5%** | 74.7% |
| Средняя цена | **$10.36** | $7.08 |
| Медиана рейтинга | **85.1%** | 80.0% |

- Рейтинг Metroidvania **статистически значимо выше** (p < 0.0001, тест Манна-Уитни)
- Размер эффекта — средний (rank-biserial = 0.154)
- 1% игр (1 128 штук) формируют 80% всех отзывов (ABC-анализ)

## Выводы

- Выше средний рейтинг
- Выше средняя цена (готовность аудитории платить)
